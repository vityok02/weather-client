# Weather Dashboard App

This is a small Angular application that displays the current weather using an open API.
The project is designed to practice with Angular, components, RxJS, services, and internationalization.

Live: [Weather App](https://vityok02.github.io/weather-client/)

## Main Features

- Search weather by location
- Current weather, daily and weekly forecast
- Hourly forecast and weather graph
- Language switcher (internationalization)
- Real-time data fetching via API (WeatherAPI)
- Component-based architecture

## Getting Started

``` bash
git clone https://github.com/vityok02/weather-client.git
cd weather-client
npm install
ng serve
```

Then open http://localhost:4200 in your browser.
